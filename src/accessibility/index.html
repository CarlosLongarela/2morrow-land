Accessibility

2Morrow.land aims to conform to WCAG 2.2 level AA.

The website is designed for keyboard navigation, visible focus, sufficient contrast, reduced-motion preferences, semantic structure and accessible forms. The core content remains available without JavaScript.

If you encounter an accessibility barrier, write to info@2morrow.land and describe the page, device and problem. We will review the report and make reasonable corrections.
